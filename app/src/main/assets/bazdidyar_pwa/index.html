بایگانی بازدیدها

در حال بارگذاری...

راهنمای استفاده بدون Android Studio

این نسخه به صورت فایل HTML اجرا می‌شود. فایل index.html را روی گوشی باز کنید، اطلاعات نمایندگی را ثبت کنید، عکس‌ها را با دوربین بگیرید و در پایان گزارش A4 را باز کنید.

برای PDF گرفتن: در صفحه گزارش، دکمه «چاپ / ذخیره PDF» را بزنید؛ سپس در پنجره چاپ گوشی، مقصد را Save as PDF انتخاب کنید.

محدودیت مهم: تشخیص خودکار پلاک در نسخه کاملاً آفلاین فعال نیست. پلاک باید دستی وارد شود. برای OCR پلاک باید نسخه اندروید یا سرور هوش مصنوعی داشته باشیم.

خروجی PDF: این نسخه علاوه بر صفحه چاپی، یک PDF داخلی قابل دانلود و اشتراک‌گذاری می‌سازد. در بعضی گوشی‌ها اگر Web Share API فایل را پشتیبانی نکند، دکمه دانلود را بزنید و سپس فایل را از پوشه Downloads منتقل کنید.

بایگانی عکس‌ها: برای هر عکس دو نسخه نگهداری می‌شود: نسخه سبک برای PDF و نسخه باکیفیت‌تر برای چاپ تکی، کنترل مجدد یا ارسال جداگانه. از بخش بایگانی می‌توانید عکس‌ها را جداگانه نمایش و چاپ کنید و همچنین همه عکس‌ها را یکجا در قالب فایل ZIP دانلود نمایید.

ردپای مالکیت: در PDF، واترمارک عکس‌ها، فایل ZIP و راهنما عبارت رسمی «پنگ | ایده، طراحی و توسعه: فاضل رحمانیان | بیمه ایران شعبه جهرم» درج می‌شود تا منبع و مالکیت خروجی روشن بماند.
